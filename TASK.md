Тестовое задание: Управление балансами игроков
Описание задачи:
Разработать React-приложение для отображения списка устройств и управления балансами игроков. Приложение должно взаимодействовать с API через Swagger и обеспечивать удобный интерфейс для финансовых операций.
API:
Swagger документация: https://dev-space.su/swagger/index.html
Функциональные требования:

Список устройств

Получить и отобразить список устройств с API
При клике на устройство открыть список игроков этого устройства


Список игроков

Отобразить игроков с их именами и текущими балансами
Реализовать операции с балансом каждого игрока


Операции с балансом

Поле ввода суммы с валидацией
Кнопки "Deposit" (пополнить) и "Withdraw" (снять)
Валидация: сумма не более 2 знаков после запятой (например, 100.50 ✓, 100.567 ✗)
Обязательно: в комментарии к коду объясните, почему такая валидация важна в финансовых приложениях


Обработка ошибок

Показывать уведомления при ошибках от сервера (недостаточно средств, некорректная сумма и т.д.)
Валидировать поле ввода
Понятные сообщения об ошибках для пользователя



Технические требования:

Обязательно: React, TypeScript, React-Bootstrap (или Bootstrap)
На выбор: state management, библиотеки для работы с API, UI компоненты
Адаптивный дизайн (мобильные и десктопные устройства)
Чистый код с комментариями
Продуманная архитектура компонентов

Что оценивается:

Архитектура приложения и структура компонентов
Типизация TypeScript
Обработка асинхронных операций и ошибок
Валидация и UX
Качество и читаемость кода
Адаптивность интерфейса
