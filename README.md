# Balance Checker

Тренировочный проект, созданный для закрепления знаний React и изучения инструментов фронтенд-разработки.

Приложение позволяет просматривать список устройств, получать список пользователей выбранного устройства и управлять балансом каждого пользователя посредством пополнения или списания средств.

## Возможности

- Просмотр списка устройств
- Просмотр пользователей выбранного устройства
- Отображение текущего баланса пользователя
- Пополнение баланса
- Списание средств
- Валидация пользовательского ввода
- Поддержка русского и английского языков
- Обработка ошибок API с отображением уведомлений (Toast)

## Работа с API

Приложение использует предоставленное открытое API.

Реализованы:

- получение списка устройств;
- получение пользователей устройства;
- изменение баланса пользователя;
- обработка всех ошибок, возвращаемых сервером.

---

## Валидация

Поле изменения баланса допускает:

- только числовые значения;
- число больше нуля;
- не более двух знаков после десятичной точки;
- корректный формат числа.

Некорректные данные не отправляются на сервер.

---

## Обработка ошибок

Все ошибки API отображаются пользователю в виде Toast-уведомлений.

Обрабатываются:

- ошибки загрузки данных;
- ошибки сервера;
- ошибки изменения баланса;
- невозможность списания средств;

## Локальный запуск

### Клонирование проекта

```bash
git clone <repository-url>
cd test_1
```

### Установка зависимостей

```bash
npm install
```

### Создание `.env`

Создайте файл `.env` в корне проекта и добавьте:

```env
VITE_API_URL=https://dev-space.su/api/v1/a/devices
```

### Запуск

```bash
npm run dev
```
